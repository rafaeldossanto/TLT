Good morning everyone, thanks for joining the call. Let me walk you through the status of the migration. Last sprint we finished moving the authentication service off the legacy database, and the read replicas are now handling about sixty percent of the query load. The latency numbers look good, we dropped from four hundred milliseconds at the ninety fifth percentile down to about ninety. There are two open risks I want to flag. First, the message queue is still a single point of failure, we have not set up the mirrored cluster yet, and if that node goes down during business hours we lose roughly twenty minutes of events. Second, the API gateway configuration is still managed by hand, which means every deployment needs someone with production access. I would like to prioritize the queue work this sprint and push the gateway automation to the next one. Any questions before we move on to the roadmap?
